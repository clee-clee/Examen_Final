# LeeFlix

Aplicación tipo Netflix con React + Vite que consume https://rickandmortyapi.com

## Cómo ejecutarla
1. Instala Node.js (versión 18 o superior).
2. En esta carpeta: `npm install`
3. `npm run dev` y abre la dirección que muestra la terminal (normalmente http://localhost:5173).

Usuario de demostración: **admin** / contraseña **1234**.
